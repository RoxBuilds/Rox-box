# Switches

Every `VICTORY_*` environment variable the source reads. This file is generated by `cargo xtask switches`: do not edit it by hand. There is no hand-written list on purpose; each switch is read where it is used and described in a comment there, and this reference is collected from those comments.

To add a switch, write it in the code (`switch::on`, `toggled!` or a value read), describe it in a comment directly above the read, and run `cargo xtask switches`. `cargo xtask switches --check` (and `cargo test`) fail when this file is stale. `scripts\play.ps1` clears every other `VICTORY_*` variable; see [ARCHITECTURE.md](../ARCHITECTURE.md#configuration-and-switches).

455 switches: 8 paths, 19 in `victory`, 6 in `victory-core`, 345 in `victory-gpu`, 29 in `victory-hle`, 8 in `victory-loader`, 40 in `victory-shader`.

How to read the tables:

- **Kind**: `on unless 0` is `toggled!` (on unless the value is `0`, read once); `off unless set` is `switch::on` (off unless set to something other than `0`); `value` is anything else, parsed where it is read. **shader cache key** marks a switch the shader translator reads: it is collected as `victory-shader/build.rs` does and its value is part of the shader cache key. **diagnostics builds only** marks a switch whose every read sits in an item or module under `#[cfg(feature = "diagnostics")]`.
- **Set by launcher**: what `Get-RunSettings` in `scripts/play.ps1` sets by default, and under which launcher options (`-Safe`, `-Fast`, `-RayTracing`).
- **Description**: the comment block directly above the first read that has one, cut to 400 characters. Empty when the code has no such comment.
- **Where**: every file that reads it. Line numbers are left out so that unrelated edits do not make this file stale.
- The scan is a heuristic, not a parser. It misses names built at run time (`format!`), counts only a string that is exactly the name, ignores reads in tests, and files its section by the crate of the first read that has a description. The diagnostics marker follows `#[cfg]` attributes on items, modules and `mod` lines only.
